## 📖 מהי המערכת הזו? (What is this system?)
מערכת **STEGO-CORE** (או STEGNO-MAIL) היא פלטפורמת תקשורת סודית וייחודית המאפשרת למשתמשים להעביר מסרים חסויים לחלוטין. 

במקום להצפין את הטקסט באופן שמעורר חשד (מה שנראה כמו רצף תווים חסר משמעות), המערכת משתמשת בטכניקת ה**סטגנוגרפיה (Steganography)** – אמנות הסתרת מידע בתוך קבצי מדיה תמימים למראה (תמונות ואודיו), כך שהשינוי אינו נראה לעין ואינו נשמע לאוזן האנושית.

הקובץ המכיל את המסר הסודי נשלח דרך "תיבת הדואר" הפנימית של המערכת אל הנמען, שיוכל לחלץ ממנו את המידע.

## 📸 תצוגת המערכת והמסכים (Screenshots & Flow)

להלן פירוט מדויק של המסכים במערכת, כפי שפותחו באמצעות Vaadin Framework בארכיטקטורת SPA:

### 1. כניסה (Login & Register)
שער הכניסה הראשי של המערכת. מנוהל באמצעות Event-Driven Authentication מתקדם ללא רענון עמוד, המגן על דפי המערכת הפנימיים. כמו כן קיים ממשק "הרשמת סוכן" להוספת משתמשים לרשת התקשורת הסגורה.

### 3. תיבת דואר נכנס (Secure Inbox)
תיבת דואר מאובטחת ואינטראקטיבית הכוללת:
* **Grid נתונים חכם:** תצוגת שולח, תוכן גלוי (המתרחב לחלון מודאלי נוח לקריאה), קובץ מצורף, וכפתור מחיקה מהירה הפועל ב-Thread נפרד כדי למנוע תקיעות במסך.
* **תצוגה מקדימה (Media Preview):** כפתור מובנה בטבלה המאפשר צפייה וניגון של התמונה או האודיו ישירות מהתיבה.
* **הודעה חדשה:** פתיחת דיאלוג ליצירה ושליחת הודעות עם אפשרות להטמעת מסר סטגנוגרפי בזמן אמת.

### 4. סטודיו הצפנה וחילוץ (Stegno Studio)
הליבה של המערכת, המאפשרת טיפול בקבצים מקומיים באמצעות ממשק כרטיסיות (Cards):
* תמיכה בהעלאת קבצי PNG, JPG, WAV.
* כפתורי פעולה חכמים: Embed (להצפנה) ו-Extract (לחילוץ).
* **השוואה חזותית מובנית:** המערכת מציגה זה לצד זה את "הקובץ המקורי" אל מול "הקובץ לאחר ההטמעה" באמצעות הזרמת Base64 ישירה ל-DOM, כולל נגן אודיו מובנה ולינק להורדת הקובץ המוצפן.

## 🚀 תכונות מרכזיות (Key Features)
* **הסתרת מידע מתקדמת (Steganography):** שימוש באלגוריתמים כמו PVD, LSB ו-F5 המונעים פגיעה ויזואלית בתמונות או רעשי רקע באודיו.
* **ארכיטקטורת SPA (Single Page Application):** המערכת מנוהלת בעמוד אחד עם ניתוב שקט (ללא טעינת דף מחדש), ניהול סשנים (VaadinSession) ורענון נתונים אסינכרוני (`ui.access`).
* **אבטחה וניהול זיכרון:** סינון כניסה לפי משתמש מחובר בלבד, ומחיקת קבצי Temp מהשרת באופן יזום (Garbage Collection ידני) למניעת עומסים ודליפות מידע.
* **עיבוד רקע:** תהליכי ההטמעה והחילוץ רצים ברקע עם ספינר (ProgressBar) המאפשר למשתמש לעצור או לבטל פעולות באמצע התהליך.
* **המרת קבצים בענן (CloudConvert API):** אינטגרציה מלאה עם שירותי ענן להמרת פורמטים של קבצי מדיה בזמן אמת, להבטחת תאימות אופטימלית.

## 🛠️ טכנולוגיות וכלי פיתוח (Tech Stack)
* **צד שרת (Backend):** Java, Spring Boot (ניהול הרשאות, REST API, ניהול תלויות).
* **צד לקוח (Frontend):** Vaadin Framework (ממשק משתמש דינמי מבוסס Java מלא).
* **מסד נתונים (Database):** MongoDB (אחסון מהיר וגמיש של משתמשים והודעות).
* **שירותי רשת (APIs):** CloudConvert API באמצעות OkHttpClient.
* **ארכיטקטורה ועיצוב:** תכנון N-Tier Architecture ואפיון מונחה עצמים.
